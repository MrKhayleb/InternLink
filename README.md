# InternLink

**Connecting students with opportunities.**

InternLink is a job and internship platform built to close the gap between students looking for real opportunities and companies looking to hire them. Instead of internship listings scattered across WhatsApp groups, Facebook pages, and outdated university portals, InternLink brings everything into one searchable, purpose-built platform.

## The Problem

Finding internships and entry-level roles as a student is harder than it should be. Listings are scattered, hard to search by skill, and often outdated. Most job platforms are built for experienced professionals — not for students taking their first step into the workforce. InternLink is built specifically for that gap.

## Features

- 🔍 **Job search** — search internships and jobs by title or skill, with location filtering
- 👤 **Student/Job Seeker accounts** — browse listings and apply directly
- 🏢 **Company/Employer accounts** — post openings and manage applicants
- 🛠️ **Admin dashboard** — oversee users, companies, and job postings
- 📱 **Responsive design** — built for a clean experience across devices

## Tech Stack

- **Backend:** PHP, MySQL
- **Frontend:** HTML, CSS, JavaScript
- **Tools:** VS Code, XAMPP (local development)

## User Roles

InternLink is designed around three distinct user types:

1. **Student / Job Seeker** — search and apply for opportunities
2. **Company / Employer** — post jobs and review applicants
3. **Admin** — manage the platform end to end
